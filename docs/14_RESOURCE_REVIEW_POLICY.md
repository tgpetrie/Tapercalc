# Resource Review Policy

Last updated: 2026-07-07

Compass resources must earn trust. They are supportive and educational, not medical instructions.

## Accepted Source Types

Preferred:

- government health agencies
- recognized crisis support organizations
- clinical guideline organizations
- major nonprofit health organizations
- public education pages from reputable institutions

Allowed with review:

- community organizations
- support communities
- articles from reputable medical publishers
- internal Compass worksheets

Avoid:

- sales pages
- unverified blogs
- influencer content
- miracle claims
- paywalled essential safety information
- content that recommends medication changes without clinician framing

## Required Resource Fields

Each resource must include:

- id
- title
- category
- description
- url or internal worksheet status
- sourceName
- cost
- type
- tags
- region
- lastReviewed

## Categories

- Urgent / Crisis Support
- Medication / Taper Education
- Finding Professional Support
- Daily Coping Tools
- Support Communities
- Printable Tools

## Review Cadence

Minimum:

- urgent/crisis resources: review every 3 months
- clinical/medication resources: review every 6 months
- worksheets/internal resources: review with each product release

## Regionalization

Resources must show region.

Urgent resources should not assume all users are in the United States unless the app has region context. US resources may be starter defaults, but future versions need region-aware support.

## Crisis Resource Prominence

Urgent help must be reachable from daily flows.

Urgent resources should be visually clear but not alarmist. Do not show crisis language as the dominant daily product experience unless the user asks for urgent support.

## Resource Disclaimer

Required language:

```text
Resources are educational and supportive. They do not replace medical care or emergency services.
```

## Add Resource Checklist

Before adding a resource:

- source is reputable
- link is public
- category is correct
- description is plain
- no medical instruction is framed as Compass advice
- cost is marked
- region is marked
- lastReviewed is current
- resource does not conflict with Product Constitution
