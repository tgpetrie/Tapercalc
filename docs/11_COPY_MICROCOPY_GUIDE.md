# Copy and Microcopy Guide

Last updated: 2026-07-07

Compass copy must be plain, truthful, calm, and non-shaming.

## Voice

Compass sounds:

- clear
- steady
- practical
- respectful
- honest about uncertainty

Compass does not sound:

- motivational
- cute
- clinical without warmth
- alarmist
- patronizing
- falsely certain

## Core Sentence

Compass does not celebrate perfect tapering. Compass celebrates staying engaged with the journey.

## Preferred Terms

Use:

- Today
- Journey
- Route
- Current Position
- Beginning
- Destination
- Estimated Completion
- Continuity
- Check-in
- Rest Point
- Hold
- Logged
- Saved
- Support
- Clinician
- Trusted support person

Avoid:

- Dashboard, when Today is meant
- compliance
- adherence score
- perfect streak
- failed
- off track
- relapse, unless clinically necessary and user-provided
- safe schedule
- recommended taper
- guaranteed

## Confirmation Messages

Preferred:

- "Today's check-in has been recorded."
- "Check-in saved."
- "Your route has been updated."
- "Plan saved."
- "Resource opened in a new tab."

Avoid:

- "Great job!"
- "You're crushing it!"
- "Perfect day!"
- "You did it!"

## Error and Warning Messages

Errors should identify the problem and the next step.

Use:

```text
Please enter at least one dose greater than 0 mg.
```

```text
Target dose must be lower than the current total daily dose.
```

```text
This hold overlaps another hold. Adjust the start day or length.
```

Avoid:

```text
Invalid.
```

```text
Oops.
```

```text
You made a mistake.
```

## Support Copy

Support copy may normalize difficulty but must not give medication instructions.

Use:

```text
This can happen. Log what happened so your record stays accurate.
```

```text
A rest point can be part of staying engaged.
```

```text
For medication-specific next steps, contact your prescriber or pharmacist.
```

Avoid:

```text
Just push through.
```

```text
You should hold your dose.
```

```text
This is normal and nothing to worry about.
```

## Calculation Copy

Use:

- "Estimated completion"
- "Based on your current route"
- "Assumes no route changes"
- "Calculated from current dose"
- "Calculated from original dose"

Avoid:

- "You will complete"
- "This will be safe"
- "Recommended by Compass"

## Empty States

No route:

```text
Start by plotting a route in Journey.
```

No check-ins:

```text
No check-ins yet.
```

No resources found:

```text
No resources match this search.
```

## Button Labels

Primary:

- Continue Journey
- Save Check-in
- Plot My Course
- Save Plan

Secondary:

- Open Route
- Print Route
- Export CSV
- Guide
- Close

## Banned Copy Patterns

Do not use:

- guilt
- toxic positivity
- false certainty
- urgent language for non-urgent states
- achievement language tied to dose reduction
- social comparison
