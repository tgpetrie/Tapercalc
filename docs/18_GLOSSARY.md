# Glossary

Last updated: 2026-07-07

## Beginning

The starting total daily dose for a route.

## Check-in

A daily record of what happened. A check-in may include completed, late, missed, or adjusted doses, notes, symptoms, support needs, or rest points.

## Continuity

The user's ongoing engagement with their journey. Continuity is preserved by honest logging, not perfect adherence.

## Current Position

The user's current total daily dose or current point in the plotted route.

## Destination

The target daily dose entered for the route.

## Estimated Completion

The projected date a route reaches the target based on current inputs and assumptions. It is not a promise.

## Hold

A planned period where no reduction occurs. Also called a rest point in product language.

## Journey

The broader taper path from beginning to destination, including planning, route, daily check-ins, holds, and support.

## Living Mode

Daily mode. The user sees today, logs what happened, and accesses support. It should take under one minute.

## Planning Mode

Route editing mode. The user changes doses, strategy, frequency, target, rest points, and advanced settings.

## Plot My Course

The action that generates a route from current planning inputs.

## Rest Point

User-facing term for a hold. A rest point is a valid part of staying engaged.

## Route

The calculated day-by-day plan generated by the taper engine.

## Route Day

The numbered day within a plotted route.

## Support Needed

A check-in status indicating the user may need help, a conversation, or a follow-up. It is not a failure state.

## Today's Step

The daily check-in flow opened from Today.

## Taper Engine

The isolated calculation module that generates route output from planning inputs.
